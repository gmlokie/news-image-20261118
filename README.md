## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024 PNG) to `$MAKEFUN_OUTPUT_DIR` (default `/output`). Stdlib only, no network, deterministic — both runs write the same bytes. The image is rendered offline by `render.py` (Pillow) and shipped in this repo.
